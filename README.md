# Fundamentos de Java para Principiantes

## Acerca de este Proyecto

Este repositorio contiene todo el código fuente y materiales para el curso "Fundamentos de Java para Principiantes", diseñado específicamente para estudiantes de secundaria (12-17 años) sin experiencia previa en programación.

**Objetivo:** Introducir los conceptos básicos de Java y Programación Orientada a Objetos (POO) de forma clara, accesible y práctica.

## Características del Curso

- 100% Online - No requiere instalación de software
- Duración: ~60 minutos en video
- 7 Lecciones progresivas y prácticas
- Enfoque en POO desde conceptos básicos
- Ejercicios interactivos en cada lección

## Contenido del Curso

### Lección 1: Introducción y "Hola Mundo" en Java (5-7 min)
- Introducción a la programación
- ¿Qué es Java?
- Primer programa: "Hola Mundo"

### Lección 2: Variables y Tipos de Datos (8-10 min)
- Declaración de variables
- Tipos de datos: `int`, `String`, `double`
- Operaciones básicas y concatenación

### Lección 3: Condicionales if-else (8-10 min)
- Decisiones simples
- Comparaciones
- Ejemplos prácticos (edad, notas)

### Lección 4: Bucles for y while (8-10 min)
- Repetición de tareas
- Contadores
- Tablas de multiplicar

### Lección 5: Métodos Simples (8-10 min)
- Crear y usar métodos
- Parámetros y valores de retorno
- Reutilización de código

### Lección 6: Introducción a la POO: Clases y Objetos (10-12 min)
- Concepto de clases y objetos
- Atributos y métodos
- Crear clase "Estudiante" o "Mascota"

### Lección 7: Proyecto Final y Cierre (10 min)
- Mini aplicación con POO
- Ejemplo: "Registro de Estudiantes"
- Resumen y próximos pasos

## Cómo Usar este Repositorio

### Para Estudiantes:

1. **Ve al documento del curso:** [course-plan.md](./course-plan.md)
2. **Sigue las lecciones en orden:** Cada lección tiene un video explicativo
3. **Practica con los enlaces directos:** Abre los editores online sin registrarte
4. **Consulta los ejemplos:** Revisa `completed-examples/` si necesitas ayuda

### Para Instructores:

1. **Revisa el plan del curso:** Todo está documentado en `course-plan.md`
2. **Accede al código fuente:** Los archivos en `starter-files/` y `completed-examples/`
3. **Personaliza según necesites:** Todo el código es reutilizable

## Filosofía del Curso

Este curso sigue estos principios pedagógicos:

1. **Aprender Haciendo** - Práctica inmediata después de cada concepto
2. **Sin Barreras** - Herramientas 100% online y gratuitas
3. **Progresión Gradual** - De lo simple a lo complejo
4. **Ejemplos Reales** - Proyectos que los estudiantes pueden relacionar
5. **POO desde el Inicio** - Introducir conceptos de objetos tempranamente

## Prerequisitos

- Ninguno - Este curso está diseñado para principiantes absolutos
- Solo necesitas ganas de aprender y un navegador web
